# Duke University — Image and Video Processing: From Mars to Hollywood with a Stop at the Hospital (Coursera)

Module notes and practice notebooks for the Duke image and video processing course on Coursera.
The course is graded by quizzes (the MATLAB exercises are optional), so each module has a `notes.md`
summary of the quiz topics and a self-made notebook that implements the methods from scratch.

| Module | Notes | Notebook |
|---|---|---|
| 1. Fundamentals | [notes](module-1/notes.md) | [Sampling, quantization, adjacency, rotation and scaling](module-1/1_sampling_quantization_geometry.ipynb) |
| 2. Image compression | [notes](module-2/notes.md) | [Entropy, Huffman, predictive coding, JPEG-style DCT](module-2/2_image_compression.ipynb) |
| 3. Spatial processing | [notes](module-3/notes.md) | [Contrast, histogram equalization, median, NL-means](module-3/3_spatial_processing_and_enhancement.ipynb) |
| 4. Image restoration | [notes](module-4/notes.md) | [Noise models, inverse vs Wiener filter](module-4/4_noise_and_restoration.ipynb) |
| 5. Image segmentation | [notes](module-5/notes.md) | [Otsu, multi-level Otsu, Hough lines and circles](module-5/5_segmentation_otsu_hough.ipynb) |
| 6. Geometric PDEs | [notes](module-6/notes.md) | [Curvature, heat vs TV diffusion, level sets](module-6/6_geometric_pdes_and_level_sets.ipynb) |
| 7. Image and video inpainting | [notes](module-7/notes.md) | [Laplace and exemplar inpainting, temporal median, film scratches](module-7/7_image_and_video_inpainting.ipynb) |
| 8. Sparse modeling and compressed sensing | [notes](module-8/notes.md) | [OMP, DCT and K-SVD dictionaries, compressed sensing](module-8/8_sparse_modeling_and_compressed_sensing.ipynb) |

All notebooks are executed with outputs and use synthetic images only (no downloads).
Requirements: `numpy`, `matplotlib`.
